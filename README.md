# 📱 TetherVPN

Простой и надежный инструмент для раздачи и приема VPN-трафика через мобильную точку доступа (Wi-Fi / Hotspot / USB) между смартфонами и компьютерами.

---

## 📦 Файлы для загрузки

| Файл | Назначение | Платформа |
| :--- | :--- | :--- |
| 📥 **[`TetherVPN.apk`](TetherVPN.apk)** | Приложение для раздачи и приема VPN | Android 8.0 – 14+ |
| 📥 **[`TetherVPN.exe`](TetherVPN.exe)** | Программа для перенаправления интернета ПК через VPN телефона | Windows 10 / 11 (x64) |

## 🚀 Инструкция по использованию

### Сценарий 1: Раздача VPN со смартфона (Режим сервера)
Используется на телефоне, на котором уже работает ваш VPN (v2rayNG, Clash, WireGuard, Outline, Amnezia и др.).

1. **Включите раздачу интернета:**
   - Включите **Точку доступа Wi-Fi (Мобильный хотспот)** или **USB-модем** в настройках смартфона.
2. **Проверьте настройки вашего VPN-клиента:**
   - Если в вашем VPN включено *«Раздельное туннелирование»* (Per-App Proxy), обязательно **поставьте галочку / разрешите TetherVPN**.
3. **Запустите раздачу в TetherVPN:**
   - Откройте **TetherVPN** на телефоне.
   - На вкладке **«Раздача VPN»** нажмите большую кнопку **«Включить раздачу»**.
   - На экране отобразится статус `ОНЛАЙН`, локальный IP-адрес (например, `192.168.43.1`) и порт (по умолчанию `8080`).

---

### Сценарий 2: Прием VPN на компьютере (Windows 10/11)
Используется на компьютере для работы через VPN телефона.

1. Подключите компьютер к Wi-Fi сети раздающего смартфона.
2. Запустите файл **`TetherVPN.exe`**.
3. Нажмите кнопку **«🔍 Автопоиск прокси»** — программа автоматически найдет раздающий смартфон в сети и проверит связь.
   *(Либо введите IP-адрес телефона и порт `8080` вручную).*
4. Нажмите **«Включить проксирование (TetherVPN)»**:
   - Весь сетевой трафик Windows, браузеры, Telegram, Git и консольные утилиты мгновенно начнут работать через телефонный VPN.
5. Когда закончите работу, нажмите кнопку **«Сбросить настройки (Вернуть обычный Wi-Fi)»**.

---

### Сценарий 3: Прием VPN на втором смартфоне (Режим клиента)
Используется на телефоне, которому нужен VPN-интернет от первого телефона.

1. Подключите второй смартфон к точке доступа Wi-Fi первого смартфона.
2. Откройте **TetherVPN** на втором смартфоне и перейдите на вкладку **«Подключение»**.
3. Нажмите кнопку **«Шлюз Wi-Fi»** — IP-адрес первого телефона подставится автоматически.
4. Нажмите **«Проверить прокси»** — приложение сделает контрольный запрос и покажет пинг (например, `✅ Прокси отвечает! Пинг: 38 мс`).
5. Нажмите **«Подключиться к VPN»** и подтвердите системный запрос Android на включение туннеля.
   - *Альтернативный способ без VPN-разрешения:* вы также можете прописать этот IP и порт напрямую в свойствах подключенной сети Wi-Fi (Настройки Wi-Fi ➔ Шестеренка сети ➔ Дополнительно ➔ Прокси ➔ Вручную).

## ❓ Частые вопросы и решение проблем

- **Сайты не открываются / трафик не идет:**
  Убедитесь, что в вашем основном VPN-клиенте на раздающем телефоне включена опция *«Разрешить подключение из LAN»* (Allow LAN) или в списке раздельного туннелирования отмечен **TetherVPN**.
- **При блокировке экрана прокси выключается:**
  В TetherVPN встроен фоновый сервис с защитой от спящего режима. В настройках системы для приложения TetherVPN рекомендуется выбрать пункт «Без ограничений» (Unrestricted) в параметрах расхода батареи.
- **Брандмауэр Windows:**
  При первом запуске `TetherVPN.exe` разрешите доступ в окне брандмауэра Windows для частных сетей.
