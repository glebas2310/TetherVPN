# 📱 TetherVPN v2.0 (Windows 11 Fluent Dark)

Утилита автоматизации сетевых настроек Windows 10/11 для обхода блокировок и прозрачной маршрутизации трафика через мобильный прокси (**TetherVPN** или **Every Proxy** на смартфоне), а также мгновенного возврата к стандартному домашнему интернету / Wi-Fi без перезагрузок и сбоев домашней сети.

Интерфейс полностью переписан на современный стек **CustomTkinter** в стиле **Windows 11 Fluent Dark** со скругленными карточками, статусными бейджами, адаптивным центрированием и чистой типографикой Segoe UI.

---

## 🚀 Основные возможности

1. **🛡️ Автоматический запрос прав Администратора (UAC):**
   - Большинство системных команд (`netsh winhttp`, настройка TTL, системные службы) требуют прав администратора.
   - Скрипт при старте проверяет наличие привилегий (`IsUserAnAdmin`). Если их нет — автоматически перезапускает себя с повышением прав через системный диалог Windows UAC.
   - При сборке в `.exe` манифест администратора встраивается прямо в бинарный файл (`--uac-admin`).

2. **🔍 Автопоиск TetherVPN в локальной сети:**
   - Автоматически сканирует все доступные шлюзы (Android Hotspot `192.168.43.1`, iOS `172.20.10.1`, USB-модем `192.168.42.129`), адаптеры и активные ARP-узлы локальной сети.
   - Находит рабочий IP с запущенным TetherVPN без необходимости вручную перебирать адреса со смартфона.
   - Запускается автоматически в фоне при старте программы, либо по кнопке **«🔍 Автопоиск TetherVPN»**.

3. **🛡️ Диагностика мобильного VPN и защита от потери интернета:**
   - **Сквозная проверка интернет-трафика:** отправляет быстрые легковесные HTTP-зонды через TetherVPN, чтобы проверить, реально ли пакеты идут в интернет.
   - **Предупреждение о мертвом VPN:** если TetherVPN запущен на телефоне, но VPN отключен/завис/не пропускает трафик (`PORT_OPEN_NO_VPN`), программа выводит четкое предупреждение и предотвращает включение неработающего прокси.
   - **Определение внешнего IP и геолокации:** при успешном подключении определяет и показывает страну и город VPN-сервера (например, `Швеция, Стокгольм`) и пинг в миллисекундах.

4. **⚡ РЕЖИМ 1: «Включить проксирование (TetherVPN)»**
   - Запрашивает IP-адрес телефона (с подсказкой найденного шлюза). Порт по умолчанию — `8080`.
   - Проверяет доступность смартфона (быстрый ICMP Ping + проверка TCP-порта TetherVPN).
   - Включает системный прокси Windows в реестре (`HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings`):
     - `ProxyEnable = 1`
     - `ProxyServer = IP:PORT`
     - Принудительно обновляет кэш WinInet в памяти (`InternetSetOptionW`), чтобы браузеры мгновенно переключились на прокси.
   - Настраивает прокси для системных фоновых служб WinHTTP через консоль:
     - `netsh winhttp set proxy IP:PORT`
   - Устанавливает постоянные переменные окружения пользователя:
     - `setx HTTP_PROXY "http://IP:PORT"`
     - `setx HTTPS_PROXY "http://IP:PORT"`
     - Применяет их к текущей сессии и рассылает системное уведомление `WM_SETTINGCHANGE` (чтобы Go-бэкенд Antigravity, curl, pip, консоли подхватили прокси).
   - Настраивает глобальный прокси для Git (если Git установлен):
     - `git config --global http.proxy http://IP:PORT`
     - `git config --global https.proxy http://IP:PORT`
   - **Маскировка тетеринга/раздачи перед мобильным оператором**: фиксирует TTL=65:
     - `netsh int ipv4 set glob defaultcurhoplimit=65`
     - `netsh int ipv6 set glob defaultcurhoplimit=65`

3. **🔄 РЕЖИМ 2: «Сбросить настройки (Вернуть обычный Wi-Fi / Домашний интернет)»**
   - Полностью очищает все следы прокси во всех компонентах системы:
     - Отключает системный прокси в реестре (`ProxyEnable = 0`) и обновляет WinInet.
     - Сбрасывает WinHTTP: `netsh winhttp reset proxy`.
     - Удаляет переменные окружения из реестра (`reg delete HKCU\Environment /v HTTP_PROXY /f` и `HTTPS_PROXY`).
     - Сбрасывает прокси в Git (`git config --global --unset http.proxy`).
     - Очищает кэш DNS: `ipconfig /flushdns`.
     - Возвращает стандартный TTL Windows (128):
       - `netsh int ipv4 set glob defaultcurhoplimit=128`
       - `netsh int ipv6 set glob defaultcurhoplimit=128`

4. **💻 Современный интерфейс (GUI на Tkinter + интерактивный CLI):**
   - Графический интерфейс с темной темой, индикатором статуса сети, цветным логом действий и защитой от зависания интерфейса (все операции выполняются в фоновых потоках).
   - Консольный режим меню с цветным ANSI-выводом (`--cli`).
   - Поддержка High-DPI экранов (четкий текст без размытия на Windows 10/11).

## 📋 Требования к системе

- **ОС:** Windows 10 или Windows 11 (любая редакция, x64 / x86).
- **Python:** Python 3.8+ (используются **только стандартные библиотеки**: `subprocess`, `winreg`, `os`, `sys`, `ctypes`, `socket`, `tkinter`).
- Никаких тяжелых сторонних библиотек не требуется!

## 📱 Настройка TetherVPN / Every Proxy на телефоне (Android / iOS)

1. Включите **Точку доступа Wi-Fi (Hotspot)** или **USB-модем** на смартфоне и подключите к ней компьютер.
2. Откройте приложение **TetherVPN** (или **Every Proxy**) на телефоне.
3. Включите раздачу (или переключатель HTTP / HTTPS).
4. В приложении отобразится IP-адрес и порт, например:
   ```text
   HTTP: 192.168.43.1 : 8080
   ```
   *(или `10.x.x.x`, `172.20.10.1`).*
5. Введите этот IP-адрес в программу **TetherVPN** на ПК (или нажмите кнопку автопоиска) и нажмите **«Включить проксирование»**.

## 🏃 Быстрый запуск

### Вариант 1. Запуск через графический интерфейс (GUI)
Дважды щелкните по файлу `run.bat` или выполните в консоли:
```powershell
python proxy_switcher.py
```
*(Windows запросит подтверждение UAC для запуска от имени администратора).*

### Вариант 2. Запуск в интерактивном консольном режиме (CLI)
```powershell
python proxy_switcher.py --cli
```

### Вариант 3. Быстрые команды автоматизации
```powershell
# Включить прокси для указанного IP (порт 8080 по умолчанию):
python proxy_switcher.py --enable 192.168.43.1

# Включить прокси с другим портом:
python proxy_switcher.py --enable 192.168.43.1 --port 8888

# Включить прокси без изменения TTL:
python proxy_switcher.py --enable 192.168.43.1 --no-ttl

# Быстро сбросить в штатный режим:
python proxy_switcher.py --reset

# Проверить текущий сетевой статус:
python proxy_switcher.py --status
```

## 📦 Сборка в один автономный .EXE файл

Программу можно скомпилировать в один исполняемый файл `TetherVPN.exe`, который будет работать на любом компьютере с Windows 10/11 без необходимости устанавливать Python!

### Способ 1. В один клик (через батник)
Просто дважды щелкните по файлу:
```text
build_exe.bat
```

### Способ 2. Через терминал
```powershell
python build_exe.py
```

После завершения готовый исполняемый файл появится в папке:
```text
dist\TetherVPN.exe
```

> **Примечание:** PyInstaller компилирует файл с флагом `--uac-admin`, поэтому при двойном клике по `TetherVPN.exe` Windows автоматически покажет стандартный системный щит UAC с подтверждением прав администратора.

## 🔍 Технические детали реализации

- **WinInet:** Вызов `ctypes.windll.wininet.InternetSetOptionW` обновляет флаги `INTERNET_OPTION_SETTINGS_CHANGED (39)` и `INTERNET_OPTION_REFRESH (37)`. Это заставляет Edge, Chrome и системные службы перечитать реестр прокси без перезагрузки системы.
- **WM_SETTINGCHANGE:** Функция `SendMessageTimeoutW` рассылает широковещательное сообщение окнам Windows о смене реестра `Environment`.
- **TTL Spoofing:** Значение `defaultcurhoplimit=65` предотвращает детекцию раздачи интернета мобильными операторами (пакет, проходящий через смартфон, уменьшает TTL на 1 и становится стандартным 64). При сбросе возвращается штатный Windows TTL = 128.
