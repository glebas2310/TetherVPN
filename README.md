# 📱 EveryProxy Fluent (Android APK для OnePlus 9 Pro)

Легковесный, неубиваемый **HTTP/HTTPS-прокси** для Android-смартфонов (специально оптимизированный под **OnePlus 9 Pro / OxygenOS 11-14**), выполненный в едином дизайн-коде **Windows 11 Fluent Dark**.

---

## ⚡ Чем это лучше Every Proxy?

1. **Никаких отключений в случайный момент:**
   - В Every Proxy на смартфонах OnePlus (OxygenOS / ColorOS) служба регулярно "выбивается" агрессивным менеджером энергосбережения при выключении экрана.
   - **В EveryProxy Fluent реализован 4-уровневый щит от закрытия:**
     1. **Foreground Service:** постоянное неудаляемое уведомление Android с типом `dataSync` и приоритетом.
     2. **WakeLock (`PARTIAL_WAKE_LOCK`):** процессор смартфона не засыпает в спящем режиме.
     3. **WifiLock (`WIFI_MODE_FULL_HIGH_PERF`):** Wi-Fi радиочип не снижает мощность и частоту опроса.
     4. **Auto-Restart:** служба возвращает `START_STICKY` и немедленно восстанавливается даже при смахивании приложения из списка недавних.

2. **Только HTTP-прокси (ничего лишнего):**
   - Убраны ненужные протоколы SOCKS4, SOCKS5, PAC, DNS и лишние службы, нагружающие память.
   - Чистый и быстрый HTTP CONNECT туннелинг для HTTPS-трафика с нулевой задержкой.

3. **Сквозная маршрутизация через мобильный VPN:**
   - Весь трафик, приходящий от ПК по локальной сети (Wi-Fi Hotspot или USB), автоматически направляется во включенный на смартфоне VPN (VLESS, Shadowsocks, WireGuard и др.).

4. **Дизайн в стиле Windows 11 Fluent Dark:**
   - Темный интерфейс (`#1A1B1E`), закругленные карточки, акцентные статусные бейджи и кнопки в точности как у программы на компьютере.

## 🛡️ Обязательная настройка на OnePlus 9 Pro (OxygenOS)

В OnePlus встроены фирменные оптимизаторы RAM и батареи. Чтобы приложение работало **непрерывно сутками**:

1. **🔒 Замочек в меню «Недавние приложения»:**
   - Смахните снизу экрана, чтобы открыть список запущенных приложений.
   - Найдите карточку **EveryProxy Fluent**, нажмите на три точки (или удерживайте карточку) и выберите **«Заблокировать» (Lock)**. Теперь приложение не закроется при очистке памяти кнопкой «Очистить всё».

2. **🔋 Отключение оптимизации батареи:**
   - При первом запуске нажмите кнопку **«🛡️ Защита от закрытия (OnePlus)»** -> **«Исключить из оптимизации»**.
   - Либо вручную: *Настройки -> Батарея -> Расход батареи приложением -> EveryProxy Fluent -> Выбрать «Не оптимизировать»*.

3. **⚡ Разрешение автозапуска и фоновой активности:**
   - *Настройки -> Приложения -> Автозапуск* -> Включите тумблер для **EveryProxy Fluent**.
   - *Настройки -> Приложения -> Управление приложениями -> EveryProxy Fluent -> Использование батареи -> Включить «Разрешить работу в фоновом режиме»*.

4. **💤 Отключение засыпания Wi-Fi:**
   - *Настройки -> Батарея -> Дополнительные настройки -> Оптимизация в спящем режиме* -> Отключите, чтобы модули Wi-Fi и сети не уходили в глубокий сон при блокировке экрана.

## 🛠️ Как собрать APK

### Способ 1: Сборка в облаке GitHub (Рекомендуется, 2 минуты, без установки Android Studio)
В репозитории уже настроен готовый GitHub Action `.github/workflows/build_apk.yml`:
1. Загрузите код проекта на ваш GitHub (в открытый или закрытый репозиторий).
2. Перейдите во вкладку **Actions** -> выберите **Build Android APK**.
3. Нажмите кнопку **Run workflow**.
4. Через 2 минуты в разделе **Artifacts** появится готовый готовый `.apk` файл (`EveryProxyFluent-APK.zip`).
5. Скачайте его на OnePlus 9 Pro и установите!

### Способ 2: Сборка через Android Studio
1. Откройте папку `android_app` в **Android Studio**.
2. Дождитесь синхронизации Gradle.
3. Выберите пункт меню **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**.
4. Готовый файл появится в `app/build/outputs/apk/release/app-release-unsigned.apk` (или debug).

### Способ 3: Сборка через терминал
```bash
cd android_app
./gradlew assembleRelease
```
