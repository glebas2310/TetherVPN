# 🎮 Как работает TetherVPN: Объяснение на пальцах (будто тебе 15 лет)

Ты **абсолютно точно и правильно всё понял**! Твоя логика про 2 потока — это на 100% то, как эта штука и устроена изнутри.

Давай разложим это простым языком, на жизненных аналогиях и без занудных терминов.

## 1. В чем была главная проблема? (Тупость Андроида)

Представь, что твой телефон — это **закрытая секретная база**:
- Когда ты включаешь на телефоне свой VPN, телефон копает **секретный подземный туннель** прямо за границу (до твоего сервера). Все приложения в телефоне (Telegram, YouTube, браузер) прыгают в этот туннель и свободно летают по заблокированным сайтам.
- Но точка доступа (раздача Wi-Fi) в Андроиде сделана очень тупо. Это просто **входная дверь с улицы**.
- Когда к твоему Wi-Fi подключается ноутбук или телефон друга, Андроид такой:  
  *«О, гости с улицы! Я не пущу вас в секретный туннель, идите через парадный выход на улицу к сотовой вышке»*.

**Итог без TetherVPN:**  
На телефоне VPN работает, а ноут получает обычный интернет с цензурой и блокировками оператора.

## 2. Как TetherVPN решает это? (Схема с «Курьером»)

TetherVPN — это не просто прога, это **твой личный курьер**, который сидит внутри телефона прямо на стыке двух миров:

```
[ ТВОЙ НОУТБУК ]
       │ 
       │ 1. «Эй, принеси мне страницу YouTube!» (по локальному Wi-Fi)
       ▼
┌────────────────────────────────────────────────────────┐
│               ТВОЙ ТЕЛЕФОН С РАЗДАЧЕЙ                  │
│                                                        │
│   ┌──────────────────────────────────────────────┐     │
│   │           КУРЬЕР (TETHERVPN)                 │     │
│   │                                              │     │
│   │  Принял заказ от ноута ──► Создал свой заказ │     │
│   └───────────────────────────────────┬──────────┘     │
│                                       │                │
│             2. Прыгает в туннель      ▼                │
│   ┌──────────────────────────────────────────────┐     │
│   │     СЕКРЕТНЫЙ ТУННЕЛЬ ТЕЛЕФОНА (ТВОЙ VPN)    │     │
│   │       (v2rayNG / Clash / WireGuard)          │     │
│   └───────────────────────────────────┬──────────┘     │
└───────────────────────────────────────┼────────────────┘
                                        │ 
                     3. Несет шифрованный ящик
                                        ▼
                             [ ВЫШКА ОПЕРАТОРА ]
                                        │
                                        ▼
                           [ СЕРВЕР ЗА ГРАНИЦЕЙ ]
                                        │
                                        ▼
                                [ САЙТ YOUTUBE ]
```

### Ты абсолютно верно описал два потока:

1. **Первый поток (Канал Wi-Fi):**  
   Ноут стучится в телефон по адресу `192.168.43.1:8080`. Курьер TetherVPN открывает дверь, принимает запрос и говорит ноуту: *«Понял, стой тут, я погнал»*.

2. **Второй поток (Новый сокет внутри VPN):**  
   Курьер TetherVPN — это **местное приложение телефона**. А Андроид устроен так, что ЛЮБОЕ приложение телефона автоматически идет через включенный VPN!  
   Курьер берет запрос ноута, ныряет в VPN-туннель, пакет шифруется в нечитаемую кашу и летит на вышку оператора.

3. **Обратный путь:**  
   Сайт отвечает серверу ➔ сервер шифрует и шлет на телефон ➔ VPN расшифровывает и отдает курьеру TetherVPN ➔ курьер по локальному Wi-Fi скидывает готовое видео в браузер ноута.

Для вышки оператора это выглядит так: **«Телефон сам что-то качает через свой зашифрованный туннель»**. Никаких подключенных компов оператор не видит!

## 3. Фокус с TTL: Как не платить оператору за раздачу?

У каждого сетевого пакета есть «счетчик жизней» — **TTL** (Time To Live):
- Когда пакет выходит со **смартфона**, у него **64** жизни.
- Когда пакет выходит с **компьютера на Windows**, у него **128** жизней.
- Каждый раз, когда пакет проходит через какое-то устройство (например, через твой телефон), он теряет **1** жизнь.

**Что палит оператор без TetherVPN:**
Комп отправил пакет (128). Телефон переслал его дальше, отняв 1 жизнь:  
$128 - 1 = 127$.  
Вышка видит цифру 127 и оператор орет:  
*«Ага! Пакет пришел со значением 127, значит к телефону подключили комп! Блокируем раздачу или списываем 100 рублей за тетеринг!»*

**Что делает TetherVPN.exe на компе:**
Программа при запуске говорит винде:  
*«Так, Windows, с этого момента всем исходящим пакетам ставь начальную жизнь не 128, а ровно 65!»*

Теперь смотри математику:
$$65 - 1 = 64$$
Пакет пролетел через телефон, стал равен **64**, вышка оператора смотрит на него и думает:  
*«О, ровно 64 жизни! Это сам телефончик сидит в Тиктоке, всё легально, плату не берем!»* 🤫

## 4. Почему важно «Раздельное туннелирование» (Галочка в VPN)?

У многих в VPN-приложениях (например, v2rayNG) включена функция: *«Пускать в VPN только выбранные приложения»* (чтобы Сбербанк и Госуслуги работали без VPN, а Инстаграм через VPN).

Если в этом списке **нет галочки на TetherVPN**:
- Наш курьер TetherVPN попытается прыгнуть в секретный туннель, а охранник VPN скажет: *«Эй, тебя нет в списке! Иди через обычную дверь»*.
- Курьер пойдет мимо VPN к оператору, и оператор всё заблокирует.

> **Мораль:** Дай курьеру TetherVPN пропуск — поставь на него галочку в твоем VPN-клиенте.
